S3 Browser

Browse public (anonymous-read) S3 buckets. Enter a bucket name or S3 URI above, or try one of these:

  • aind-open-data
  • allen-brain-cell-atlas
  • dandiarchive
  • openneuro.org

The bucket must allow public listing and send CORS headers. Everything runs in your browser; nothing is sent anywhere except S3.

Actions

S3 lists keys in lexicographic order. Sorting by size or date applies to the current page only.
